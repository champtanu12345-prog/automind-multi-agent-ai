# AutoMind – Multi-Agent AI Automation System

## Overview

AutoMind is an intelligent AI automation
system that uses multiple specialized AI
agents to complete research and reporting tasks.

The system uses LangGraph to coordinate
four AI agents.

## AI Agents

1. Research Agent
2. Analysis Agent
3. Fact-Checking Agent
4. Report Writer Agent

## Technologies Used

- Python
- LangGraph
- LangChain
- Groq LLM API
- Streamlit
- Google Colab
- GitHub

## Architecture

User Input
    |
Research Agent
    |
Analysis Agent
    |
Fact-Checking Agent
    |
Report Writer Agent
    |
Final Report

## Main Features

- Multi-agent collaboration
- Automated research workflow
- AI-powered analysis
- Fact-checking review
- Professional report generation
- Interactive Streamlit interface
- Downloadable reports

## Installation

Install the dependencies:

pip install -r requirements.txt

Set your GROQ_API_KEY environment variable.

Run the application:

streamlit run app.py

## Execution Environment

The project can be tested using Google Colab.
